# Data Import — Listings

Import drone service listings from a CSV file into the TypeScript data layer.

## Quick start

1. Copy `listings-template.csv` → `listings.csv` (same folder)
2. Fill in your listings data
3. Run:
   ```bash
   npm run import:listings
   ```
4. The output file `src/data/listings.generated.ts` will be created/overwritten

## CSV format

- Encoding: **UTF-8** (required for Hebrew text)
- Delimiter: comma (`,`)
- Quoted fields: wrap in `"..."` if the value contains commas or newlines
- Comment lines: start with `#` — ignored by the parser
- Blank lines: ignored

### Column reference

| Column | Required | Format | Notes |
|--------|----------|--------|-------|
| `id` | ✅ | string | Unique, stable identifier (e.g. `biz-001`) |
| `name` | ✅ | string | Business display name in Hebrew |
| `slug` | ✅ | string | URL slug — lowercase, hyphens (e.g. `sky-vision-tlv`) — must be unique |
| `categorySlug` | ✅ | see below | One of the 10 valid category slugs |
| `citySlug` | ✅ | see below | One of the 10 valid city slugs |
| `shortDescriptionHe` | ✅ | Hebrew string | 1–2 sentences shown in listing cards |
| `longDescriptionHe` | ✅ | Hebrew string | Full description shown on listing page |
| `claimedStatus` | ✅ | `claimed` / `unclaimed` / `pending` | |
| `qualityScore` | ✅ | integer 1–5 | Internally converted to 0–100 (×20) |
| `lastUpdated` | ✅ | `YYYY-MM-DD` | Date of last data review |
| `services` | — | pipe-separated | e.g. `צילום אירועים\|צילום נדל"ן` |
| `phone` | — | string | e.g. `050-1234567` |
| `whatsapp` | — | string | Same format as phone |
| `website` | — | URL | Full URL including `https://` |
| `email` | — | email | |
| `imageUrl` | — | URL | Absolute URL to listing image |
| `sourceUrl` | — | URL | Where the data was sourced from |
| `featured` | — | `true` / `false` | Defaults to `false` |

## Validation

The script validates every row before writing any output. If any row fails, the entire import is aborted and the existing generated file is left unchanged.

Errors that will fail the import:
- Missing required fields
- Unknown `categorySlug` or `citySlug`
- `qualityScore` outside 1–5
- Invalid `claimedStatus` value
- Duplicate `slug` or `id`

## Output

The script writes `src/data/listings.generated.ts` — do not edit this file manually.

To use the imported listings alongside the hand-crafted sample data in `src/data/listings.ts`:

```typescript
// src/data/listings.ts
import { generatedListings } from './listings.generated'

const allListings: Listing[] = [
  ...SAMPLE_LISTINGS,   // existing sample data
  ...generatedListings, // imported from CSV
]
```

Or replace `SAMPLE_LISTINGS` entirely once you have real data.

## Google Sheets workflow

1. Maintain your listings in a Google Sheet using the same column headers
2. File → Download → Comma-separated values (.csv)
3. Save as `data-import/listings.csv`
4. Run `npm run import:listings`

For automated export, use Google Sheets' publish-to-web feature (File → Share → Publish to web → CSV) and pipe the URL into the script — but manual download is fine for an MVP.
